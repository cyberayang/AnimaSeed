# 快速开始

[文档目录](README.md) / 快速开始

## 1. 安装与初始化

需要 Node.js **24.14.0 或更新版本**。

```sh
git clone https://github.com/cyberayang/AnimaSeed.git
cd AnimaSeed
npm ci --ignore-scripts
npm run build
node dist/cli/main.js workspace-init
```

初始化会创建本地人生档案，并在 `AGENTS.md` 中加入日常对话引导，保留已有规则。重复初始化会继续使用原来的身份。

| 路径 | 用途 |
| --- | --- |
| `data/soul/` | 保存身份、记忆和成长记录 |
| `.soul/GUIDE.md` | 供智能体读取的日常接续步骤 |
| `.soul/workspace.json` | 绑定当前工作区与身份 |

这些私人目录已被 Git 忽略，每位使用者都从自己的独立档案开始。

## 2. 第一次起名

在能够读取工作区引导、执行本地命令的智能体中打开项目，开始日常对话。首次使用时，用明确的命名表达确认名字：

> 给你起名：小禾

也支持 `name: Willow`。普通问候不会被当作命名。

名字确认后，记录唯一的出生事件；暂时不命名，就继续等待。再次打开不会重复出生。

如果希望先在终端完成命名，可运行：

```sh
npm start
```

Windows 也可双击根目录的 `启动灵魂核心.cmd`。终端入口提供命名和状态查看，日常聊天使用接入的智能体。

> 本地档案使用 Node.js 内置的 SQLite。Node 24 会在运行命令时提示 `SQLite is an experimental feature`，该提示不影响功能；启动脚本与 `npm start` 已通过 `--disable-warning=ExperimentalWarning` 关闭它。直接运行 `node dist/cli/main.js` 时可以同样加上该参数。

## 3. 日常交流

宿主按照 `.soul/GUIDE.md` 完成记忆读取和写回，你可以像平常一样交流。

- 每次模型调用保留简短身份与核心原则，当前上下文足够时直接交流，需要时自主回忆。
- 真实输入和公开回复保存为经历。
- 有值得保留的新理解或未完成话题时，连同来源一起保存。
- 可自主维护近期生活，或提出休闲、探索与陪伴意愿，由宿主处理能力和授权。
- 较早的经历按需要检索，并可展开原话。

源码维护、调试和配置讨论不会自动成为她的日常经历。

## 4. 换一个对话窗口

继续打开同一个工作区。宿主重新读取当前快照，接续原来的名字、经历与关注，不需要重新命名。

完整人生保存在档案中；模型单次读取的内容仍受上下文容量限制。回忆通过相关记忆和原件回查补充。

## 常见情况

| 情况 | 处理方式 |
| --- | --- |
| 关闭终端后还能继续吗？ | 可以。档案保存在本地，重新打开即可载入 |
| 换模型会换一个身份吗？ | 身份和记忆不变，表达方式可能受模型影响 |
| 任意聊天平台都能直接使用吗？ | 平台需支持工作区读写，或由接入者连接生命周期接口 |
| 档案缺失或身份不符怎么办？ | 恢复并检查原档案；工作区入口会报错，避免悄悄换人 |
| 想换电脑怎么办？ | 按[档案管理](data-management.md)加密导出、导入 |

进一步接入宿主，见[接入文档](integration.md)；了解成长方式，见[记忆与成长](memory-and-growth.md)。

意愿和权限如何交给智能体处理，见[自主生活与宿主协作](agency.md)。
