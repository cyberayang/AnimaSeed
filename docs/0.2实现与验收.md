# 灵魂核心0.2 · 实现与验收

日期：2026-10-30。环境：Windows、Node.js 24.14.1、dsh 0.2.1-rc.2。所有验证使用虚构档案、本地假模型与隔离目录，不读取私人记忆、不调用收费模型、不修改正式profile。

## 实现映射

| 能力 | 代码 | 当前边界 |
| --- | --- | --- |
| 等待命名、出生、旧身份接续 | soul-lifecycle / soul-schema / CLI onboarding | 不自动改名，不把接续时间认作出生 |
| 原始互动与人生事件 | soul-life / soul-repository | 只记已提交用户输入和助手公开文字，排除原始思考与合成注入 |
| 理解变更与历史 | authorLife / revisesId | 同主题修正要新经历；过去保留，当前投影选择后继版本 |
| 问题与兴趣 | interest / interestState | 支持持续关注与解决沿革；没有联网自主行动 |
| 稳定偏好 | preference | 至少跨两天两次公开选择；仅是有来源的外部状态学习 |
| 模拟情绪 | soul-affect | 有互动与公开回应来源，去重和衰减；不证明主观感受 |
| 成长候选 | soul-growth-evidence | 先前理解、后续学习、隔日应用、实际反馈连接完整 |
| 成长复核 | host-only review / reflection | 候选至少间隔两天，不能由日常工具自评晋升；语义评价仍可能有误 |
| 连续发展与阶段 | soul-development | 六方向分别积累，阶段受时间、真实互动天数、多情境证据、观察期约束 |
| 青年后的连续性 | stage young-adult | 继续积累原件和理解，无自动衰老与离线造经历 |
| 动态工作快照 | soul-context / dsh systemPrompt.section | 默认6000或12000字符，显式可调至32000；不是精确token预算 |
| 有界空闲整理 | soul-reflection / Background | 持久队列、批次、取消、租约、默认每天12次；真实模型费用跟随宿主 |
| 隐私管理 | soul-privacy / privacy-forget | 与普通对话分开；按依赖链或明确匹配词组清除，本目录之外需另管 |
| 人生迁移 | soul-archive / soul-restore / transfer | 版本2，证据链校验和重放，完整保存出生、发展与待整理队列 |
| 单工作区接续闭环 | workspace / workspace-guide / CLI workspace | 首次引导、固定身份、每轮原话与公开回复、认识延续；宿主遵守读写约定 |

旧MemoryCore和0.1测试继续保留用于兼容管理验证，新生档案使用schema2，旧API拒绝降级打开。没有新增智能体执行循环、桌宠、语音、浏览器、通用命令或任务系统。

## 行为验收

本次 npm run check 已通过55项测试、严格类型检查、生产编译和55个自有模块的300行上限/无环依赖检查；核心无第三方运行时依赖。原npm run demo已验证SDK跨窗口；新增测试覆盖工作区与独立安装CLI的完整闭环。

当前测试包含：

- 首次打开没有默认名字，中断后继续等待；明确提交后只有一个出生事件，同一请求去重。
- 命名晚了100天，出生时长仍从命名确认计算；旧身份需明确接续，出生未知则保持未知。
- 教育不会直接改偏好，旧理解不删除，新理解保存原件和变更链；虚构选择与无证据反馈被拒绝。
- 未解问题跨窗口继续，解决后保留原问题；偏好有跨日选择依据。
- 情绪仅为有来源模拟，同一互动不重复累积，时间衰减、迁移与隐私撤回均生效。
- 80次重复“已经长大”加2000天时间，不足以让初生档案晋升。
- 六方向的虚构学习经历跨日积累并复核，只有满足多项条件才进入下一阶段。
- 模拟到青年阶段后，进一步推进到诞生3660天，没有新增离线事件或变成老年形象；整个人生迁移后状态一致。
- 整理取消、证据被删除、坏条目或租约冲突均不提交不完整结果；持久队列会分批处理早期经历，不局限于最后窗口。
- 普通工具没有删除、改人格、改年龄或直接复核成长的入口；管理清除删除原件及衍生信息。
- 隐私词组在不同原件中独立出现时，可明确使用match清理；清理后数据库与后续导出不含测试私密正文。
- 正式dsh AgentLoop验证首次命名、跨窗口延续、子智能体隔离、公开回复记录、空闲模型路由复用及插件卸载。
- 连续六次dsh请求的人生快照数量为[1,1,1,1,1,1]。旧快照不会不断累加到模型可见上下文；宿主原始日志仍受宿主管理。
- npm压缩包安装到空目录，验证编译后SDK、命名、命令行加密迁移；包里不包含数据目录或原始TypeScript运行源码。
- 工作区初始化保留AGENTS原规则与已有身份；重复执行不新增身份或重复引导段，维护对话不自动导入。
- 真实命名、用户原话、公开回复、有来源认识与未完话题经过独立CLI进程保存，重开恢复同一身份；理解修正保留旧版本。
- 数据库丢失或身份不符时报错，拒绝自动重建；回复需同会话有效用户来源；被隐私清除的输入重放被拒绝。

## 性能记录

一轮本地实测：1003条人生事件、20次当前快照准备、8000字符预算，中位2.95ms，P95 4.07ms。只覆盖本地记忆准备，不含模型生成、网络、UI或语音；硬件负载变化会影响结果。

## 未完成的质量评估

测试证明来源、时间、状态、权限边界、迁移和取消机制按设计工作，不证明她已具有人类意识或已实现人类自主成长。

仍需真实模型与长周期使用验证：反思是否忠实、偏好是否稳定、不同情境的学习是否真实迁移、关系表达是否自然、跨模型的一致性、同义表达召回、十万条以上规模和数年实际使用。当前没有本地语义向量模型、分布式人生合并或任意封闭平台的一键接入。

成长阈值和情绪衰减都是工程参数。模型的引文可通过结构检查，但“这句话是否真的支持这个心理解释”仍有语义不确定性。管理者能访问本地文件的事实不会被人格自主性设计消除。
