# 开发与测试

[文档目录](README.md) / 开发与测试

## 运行检查

需要 Node.js **24.14.0 或更新版本**。

```sh
npm ci --ignore-scripts
npm run check
```

检查包含严格 TypeScript 类型验证、生产编译、模块不超过 300 行、依赖无环、核心运行时依赖边界，以及行为测试。

查看 SDK 跨对话示例：

```sh
npm run demo
```

示例和测试使用虚构档案，不调用收费模型。GitHub Actions 在 Windows 和 Linux 上运行相同检查，最新结果见[工作流页面](https://github.com/cyberayang/AnimaSeed/actions/workflows/check.yml)。

## 测试覆盖

| 范围 | 验证内容 |
| --- | --- |
| 命名与身份 | 等待命名、唯一出生、重试去重和重开接续 |
| 记忆与认识 | 原话不可覆盖、引文校验、理解修正和未完话题 |
| 人格与情绪 | 跨日偏好、模拟情绪衰减和重复事件不叠加 |
| 成长 | 经历链、间隔复核、时间门槛和青年后继续积累 |
| 工作区 | 首次引导、公开回复来源、档案缺失和身份不符 |
| 自主回忆 | 普通交流不执行全文搜索，正式 AgentLoop 中由模型按需调用回忆 |
| 意愿与宿主 | 自由能力标识、授权回执、一次/持续范围、拒绝撤回和过期 |
| 真实活动 | 宿主执行回执、去重、来源清理和迁移后重新核验 |
| 整理 | 批次、队列、取消、租约、预算和失败回滚 |
| 隐私与迁移 | 依赖清理、防止资料复活、加密传输和坏档案拒绝 |
| dsh 适配 | 正式 AgentLoop 中的生命周期、根会话隔离和快照替换 |
| 打包 | 独立安装后 SDK、CLI、档案迁移与完整对话读写 |

## 验证范围

结构测试验证身份、来源、时间、状态、迁移和生命周期按规则工作。

长期反思是否忠实、关系表达是否自然、跨模型的一致性，以及更大规模和长期真实使用，需要持续评估。当前全文检索也不保证找到所有同义表达。

涉及行为变化时，测试应证明实际使用结果。文案与排版调整通常无需新增测试。

参与开发前，请阅读[贡献指南](../CONTRIBUTING.md)和仓库中的 `AGENTS.md`。
