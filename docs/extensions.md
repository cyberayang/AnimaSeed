# 可选扩展

[文档目录](README.md) / 可选扩展

基础使用围绕同一工作区中的人生档案展开。下面的方向由每位使用者按需要选择，具体智能体接入、模型调用和形象绑定交给宿主实现。

## 扩展概览

| 方向 | 适用情况 | 当前支持 |
| --- | --- | --- |
| 多工作区接续 | 希望同一个她参与不同项目 | SDK 可显式复用同一 `dataDir`；工作区命令尚无外部绑定入口 |
| 跨设备迁移 | 换电脑，先后使用 | 已有加密导出、导入 |
| 多端自动同步 | 不同设备同时积累经历 | 待实现 |
| 项目资料分区 | 人格连续，但项目资料有访问边界 | 待实现 |
| 语义检索 | 用不同措辞回忆同一件事 | 当前为全文检索，向量召回待接入 |
| 自动整理 | 希望减少手动保存认识 | SDK 和 dsh 适配已提供有界整理 |
| 形象与语音 | 桌宠、气泡、动画或声音 | 由接入者实现 |

## 跨工作区接续

同一电脑上，多个宿主可显式指向同一权威人生目录，避免各自维护逐渐分歧的副本。

绑定应核对身份 ID，不能只根据名字判断。同一 `dataDir` 会共享整份档案，目前没有按工作区隔离的读取权限。需要资料分区时，应同时约束原件、摘要和其他衍生内容。

不同个体使用独立档案，保持各自的经历和身份。

## 多设备同步

当前导入只接续到空目标，不是合并接口。同步若要支持离线多端，需要处理：

- 唯一事件 ID、稳定身份和来源关系。
- 并发经历与认识修正的冲突。
- 隐私清除标记的传播，防止旧副本恢复已清除内容。
- 基于合并后的证据重新计算状态，避免直接累加年龄、情绪或成长分数。

数据库文件的覆盖不能代替这些规则。先后换设备可直接使用现有的[加密迁移](data-management.md)。

## 语义检索与自动整理

语义检索可增加本地或宿主提供的嵌入模型，但需要处理索引成本、重建和隐私清除。

自动整理可以复用宿主模型，接入者负责取消、输出预算和调用费用。核心通过来源校验接收结果，不保存供应商密钥。

## 形象、语音和桌宠

形象层读取名字、阶段和状态，将输入送往绑定的宿主会话，再展示同一会话的公开回复。

保持同一身份和一份权威档案，避免界面中的独立角色提示另开一套人格与记忆。动画、随机动作和调用次数不作为成长证据。

以 dsh-pet 为例，接入者需确认原生聊天是否经过绑定会话；仅安装两个插件不会自动完成输入与回复的绑定。本仓库未提供完整的 dsh-pet 双向桥接。
