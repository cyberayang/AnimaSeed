# 第一版验收记录

这是0.1历史记录；当前0.2验收见 [0.2实现与验收.md](0.2实现与验收.md)。0.1的默认身份和直接删除接口不用于新生日常对话。

日期：2026-10-30。环境：Windows、Node.js 24.14.1、dsh 0.2.1-rc.2。只使用虚构数据与本地假模型，没有调用收费模型、迁移真实私人记忆或修改其他项目。

`npm run check` 已通过21项行为测试，以及严格TypeScript检查、生产JavaScript编译、25个自有模块的300行上限、无循环依赖和核心依赖边界检查。

已验证：

- 重开数据库、切换 dsh 会话和卸载重装插件都沿用原身份ID。
- 原件去重且不可覆盖；事实拒绝助手自述和不匹配的引文。
- 纠正使原件、旧事实和多层摘要退出召回；失败整理整批回滚。
- 来源过期传播到衍生项；显式遗忘删除来源和衍生内容，数据库文件与导出包不再含测试私密正文，相同消息无法复活。
- 跨日反复反馈才形成轻微人格变化；重复整理不叠加，单日变化受限；遗忘证据撤回相关变化。
- 模拟情绪随时间衰减；重新打开保持同一状态，不生成离线经历。
- 密码加密迁移保留身份和关系；拒绝错密码、损坏包、伪造引文和覆盖已有身份。
- 正式 dsh AgentLoop 测试中，只记录真实用户输入与公开回复；无思考泄漏、无合成资料污染、无额外云端请求。
- 用户新输入取消后台整理，取消后无推断落盘；插件卸载释放数据库。
- 1002条虚构记录、30次本地上下文准备、4000字符预算：最终一轮实测中位3.55ms，P95 6.09ms。耗时仅覆盖本地记忆准备，不含模型生成、语音或UI。
- 真实 `npm pack` 后在空目录安装压缩包，验证编译后的SDK可从 `node_modules` 运行、命令行加密导出/导入保持身份，包里不含原始TypeScript运行代码、数据库或私人数据。

未验证或仍有边界：真实模型的长期人格一致性与语义整理质量、同义表达的完整召回、十万条以上规模、数年真实使用、真实目标 profile 的安装与热更新、任意智能体一键接入。机制与数据测试通过不等于证明主观情感。

0.1使用data/default保存独立档案；该目录和本机打包产物均不随源码公开。新生流程使用data/soul，不自动迁移旧身份或修改宿主profile。
